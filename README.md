## 📖 Sobre o projeto

O **Inside Python** é uma plataforma educacional interativa desenvolvida inicialmente como projeto acadêmico no Ensino Médio Técnico em Ciências de Dados do SENAC São Paulo.

O projeto surgiu com a proposta de facilitar o aprendizado da linguagem Python, oferecendo conteúdos introdutórios de maneira clara, organizada e acessível.

Ao longo de seu desenvolvimento, evoluiu de um site educacional com materiais e videoaulas para uma aplicação web voltada à aprendizagem interativa.

Atualmente, a plataforma combina explicações escritas, execução real de código Python, exercícios e acompanhamento do progresso, permitindo que estudantes aprendam no próprio ritmo.

### 🎯 Objetivos

- Facilitar o primeiro contato com a linguagem Python.
- Tornar o ensino de programação mais acessível.
- Integrar teoria, experimentação e prática.
- Estimular o raciocínio lógico e a autonomia.
- Oferecer uma experiência de aprendizagem progressiva.
- Ajudar estudantes a compreender e corrigir erros de programação.

## ✨ Funcionalidades

Conteúdos organizados progressivamente, desde os primeiros comandos até a criação de pequenos programas.

### 🧠 Hora de Praticar

Área complementar com desafios para aplicar e revisar os conhecimentos adquiridos nas aulas.

### 📖 Glossário

Explicações acessíveis sobre termos importantes da programação.

### 🔍 Entenda o Erro

Recurso educacional que auxilia na compreensão de erros comuns encontrados durante a programação.

### 📱 Interface responsiva

Ambiente desenvolvido para utilização em computadores e dispositivos móveis.

## 🎓 Metodologia de aprendizagem

O Inside Python utiliza uma metodologia baseada em cinco etapas:

**ENTENDA → OBSERVE → EXPERIMENTE → PRATIQUE → REVISE**

| Etapa | Objetivo |
|---|---|
| **Entenda** | Compreender conceitos por meio de explicações claras. |
| **Observe** | Analisar exemplos e entender o funcionamento do código. |
| **Experimente** | Modificar e executar programas Python. |
| **Pratique** | Resolver exercícios e aplicar conhecimentos. |
| **Revise** | Consolidar o aprendizado e identificar dificuldades. |

A proposta é tornar o estudante participante ativo da aprendizagem, combinando leitura, experimentação e resolução de problemas.

## 🧠 Conteúdos abordados

A plataforma está organizada em cinco aulas principais:

**Aula 1 — Conhecendo Python**

Introdução à programação, à linguagem Python e aos primeiros comandos.

**Aula 2 — Entendendo variáveis**

Variáveis, atribuição, tipos de dados e armazenamento de informações.

**Aula 3 — Aprendendo operações**

Operadores matemáticos, cálculos, precedência e operações com variáveis.

**Aula 4 — Estruturas condicionais**

Comparações, operadores lógicos, indentação e estruturas `if`, `elif` e `else`.

**Aula 5 — Primeiros projetos**

Aplicação dos conhecimentos adquiridos no desenvolvimento de pequenos programas.

## 🚀 Como utilizar

1. Acesse o Inside Python pelo link disponibilizado no repositório.
2. Clique em **Começar Agora** ou **Continuar Estudando**.
3. Escolha uma das cinco aulas.
4. Leia as explicações e observe os exemplos.
5. Experimente códigos no editor interativo.
6. Resolva os exercícios e utilize as dicas quando necessário.
7. Acompanhe sua evolução e continue estudando.

**Não é necessário instalar Python nem criar uma conta para começar.**

## 💾 Armazenamento e privacidade

Atualmente, o progresso do estudante é registrado localmente no navegador.

Isso significa que:

- Não é necessário criar uma conta.
- O progresso pode ser preservado entre visitas no mesmo navegador.
- Não existe sincronização automática entre diferentes dispositivos.
- A limpeza dos dados do navegador pode remover o progresso salvo.

A futura implementação de contas e armazenamento em nuvem será planejada com atenção à privacidade, segurança e proteção de dados pessoais.
