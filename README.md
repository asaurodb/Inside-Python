## 📖 Sobre o projeto

O **Inside Python** é uma plataforma educacional interativa desenvolvida inicialmente como projeto acadêmico no Ensino Médio Técnico em Ciências de Dados do SENAC São Paulo.

O projeto surgiu com a proposta de facilitar os primeiros contatos com a linguagem Python, oferecendo conteúdos introdutórios acessíveis e organizados.

Ao longo de seu desenvolvimento, evoluiu de um site de materiais educacionais para uma aplicação web com recursos de aprendizagem interativa.

Atualmente, o Inside Python busca reunir teoria, experimentação e prática em um único ambiente, permitindo que estudantes aprendam programação no próprio ritmo.

### 🎯 Objetivos

- Facilitar o aprendizado de Python para iniciantes.
- Tornar o ensino de programação mais acessível e interativo.
- Integrar explicações teóricas e execução de código.
- Estimular a autonomia e o raciocínio lógico.
- Oferecer exercícios e atividades práticas.
- Permitir o acompanhamento da evolução do estudante.
- Desenvolver uma experiência educacional intuitiva e progressiva.

## ✨ Funcionalidades

## 🎓 Metodologia de aprendizagem

O Inside Python adota uma abordagem baseada em cinco etapas:

**ENTENDA → OBSERVE → EXPERIMENTE → PRATIQUE → REVISE**

| Etapa | Objetivo |
|---|---|
| **Entenda** | Aprender conceitos por meio de explicações claras e progressivas. |
| **Observe** | Analisar exemplos de código e compreender seu funcionamento. |
| **Experimente** | Modificar e executar códigos diretamente no navegador. |
| **Pratique** | Resolver exercícios utilizando os conhecimentos adquiridos. |
| **Revise** | Consolidar o aprendizado e identificar dificuldades. |

A proposta é permitir que o estudante desenvolva conhecimentos de maneira progressiva, combinando leitura, experimentação e resolução de problemas.

## 🧠 Conteúdos abordados

A plataforma está organizada em cinco aulas principais.

### Aula 1 — Conhecendo Python

Introdução à programação, à linguagem Python e aos primeiros comandos.

### Aula 2 — Entendendo variáveis

Variáveis, atribuição de valores, tipos básicos de dados e armazenamento de informações.

### Aula 3 — Aprendendo operações

Operadores matemáticos, cálculos, precedência e operações com variáveis.

### Aula 4 — Estruturas condicionais

Tomada de decisões, comparações, operadores lógicos e estruturas `if`, `elif` e `else`.

### Aula 5 — Primeiros projetos

Aplicação prática dos conhecimentos adquiridos por meio de pequenos programas.

## 🚀 Como utilizar

1. Acesse a plataforma pelo endereço disponibilizado no repositório.
2. Clique em **Começar Agora** ou **Continuar Estudando**.
3. Escolha uma das aulas disponíveis.
4. Leia as explicações e observe os exemplos.
5. Experimente os códigos no editor interativo.
6. Resolva os exercícios e utilize as dicas quando necessário.
7. Acompanhe seu progresso e continue aprendendo.

O Inside Python foi pensado para permitir o aprendizado diretamente no navegador.

**Não é necessário instalar Python para utilizar o editor da plataforma.**

## 💾 Armazenamento e privacidade

Atualmente, o Inside Python utiliza armazenamento local do navegador para registrar o progresso do estudante.

Isso significa que:

- Não é necessário criar uma conta para estudar.
- O progresso pode ser mantido entre visitas no mesmo navegador.
- Os dados de progresso não são sincronizados automaticamente entre dispositivos.
- A limpeza dos dados do navegador pode remover o progresso salvo.

O projeto está em evolução. A implementação futura de contas e armazenamento em nuvem exigirá medidas adicionais de segurança, privacidade e proteção de dados.

## 🔐 Segurança e evolução técnica

O Inside Python está sendo desenvolvido com foco em qualidade, manutenção e evolução gradual.

Entre os objetivos técnicos estão:

- Aprimorar a confiabilidade do editor Python.
- Revisar os mecanismos de correção dos exercícios.
- Expandir os testes automatizados.
- Melhorar o desempenho e a acessibilidade.
- Aplicar boas práticas de desenvolvimento seguro.
- Planejar a proteção de dados desde a concepção das futuras funcionalidades.

Isso não representa uma declaração de conformidade legal ou certificação de segurança.
