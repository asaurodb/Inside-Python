Sobre o Projeto

O Inside Python é um projeto criado por um grupo de estudantes apaixonados por tecnologia e programação. Nosso objetivo é compartilhar o aprendizado e o entusiasmo por Python com todos que buscam melhorar suas habilidades na linguagem.

Python é uma linguagem poderosa, versátil e acessível. Queremos torná-la mais próxima de todos, oferecendo materiais, dicas e projetos práticos para quem está começando ou quer se aprofundar mais.

A equipe é composta por estudantes que acreditam no poder do conhecimento colaborativo e trabalham juntos para criar um ambiente onde todos podem aprender e crescer.

Nosso propósito é compartilhar conhecimento, apresentar a linguagem Python e ajudar você a dar os primeiros passos na programação.

    Perguntas frequentes

    Como começo a estudar?

    Clique em “Comece Agora” (ou “Começar pela Aula 1”). Na primeira vez, uma apresentação rápida mostra como a plataforma funciona, e você pode pulá-la. Depois você entra na Aula 1, no primeiro tópico. Não há cadastro nem login.

    Como funcionam os tópicos?

    Cada tópico tem cinco etapas curtas: Entenda (a ideia, em linguagem simples), Observe (um exemplo explicado linha por linha), Experimente (você altera e executa o código), Pratique (exercícios do tópico) e Revise (um resumo e uma pergunta rápida). No Estudo Guiado você vê uma etapa por vez; na Navegação Livre, todas as etapas do tópico aparecem juntas. Nada fica bloqueado: você pode ir e voltar.

    Como executo os códigos?

    Nas etapas Experimente e Pratique há um editor. O botão “Executar código” roda o programa de verdade, com Python no seu navegador (via Pyodide), e mostra o resultado. Na primeira execução, o site baixa o interpretador, então é preciso internet e pode levar alguns segundos. Programas que passam de 8 segundos são interrompidos.

    Como verifico os exercícios?

    “Executar” só roda o seu programa. “Verificar resposta” testa se ele resolve o exercício: o site executa o seu código com valores diferentes e confere o comportamento, então soluções diferentes podem estar certas. O retorno diz se há erro de sintaxe, erro durante a execução, resultado diferente do esperado, resposta incompleta ou resposta correta. A verificação confere o resultado, não o jeito de pensar.

    Como uso as dicas?

    Cada exercício tem até três dicas, que aparecem uma de cada vez: primeiro uma lembrança do conceito, depois uma estratégia e, por fim, a estrutura da solução com lacunas. A solução completa só pode ser vista depois de você tentar verificar a resposta, e vem com uma explicação.

    Meu progresso fica salvo?

    Sim, mas apenas neste navegador e neste aparelho, sem cadastro. Se você limpar os dados do navegador, usar outro aparelho ou uma aba anônima, ele não será encontrado: não há sincronização entre dispositivos. O progresso serve de orientação e não bloqueia nenhuma aula.

    Como continuo de onde parei?

    Quando você tem progresso, o botão amarelo do menu vira “Continuar Estudando” e leva direto ao ponto pendente mais recente. O painel de aprendizagem, logo abaixo do início da página, mostra a aula atual, o último tópico e a próxima atividade. Só são marcados como concluídos os tópicos que você conclui e os exercícios que você acerta: abrir um conteúdo não conta.

    Preciso instalar Python no computador?

    Não. Tudo roda dentro do site. Instalar o Python só será necessário mais adiante, quando você quiser criar programas fora daqui.

    Posso estudar pelo celular?

    Pode. O menu das aulas fica recolhido, os exercícios aparecem em uma coluna e os botões têm tamanho confortável. Digitar código no celular é mais lento; para os exercícios maiores, computador ou tablet costumam ser mais confortáveis.

    O que faço quando meu código dá erro?

    Respire: errar faz parte. Leia a mensagem, que costuma dizer o tipo do erro e a linha. Clique em “Entenda este erro” para ver o que ele significa, um exemplo errado e um corrigido. Se ainda assim travar, use as dicas do exercício, uma de cada vez, e tente de novo.

    Rever a introdução não altera o seu progresso.

    Bem-vindo ao Inside Python!

    O Inside Python foi criado por estudantes para você dar os primeiros passos na programação com Python, de forma simples, interativa e no seu ritmo.

    Aqui, errar faz parte: experimente à vontade e aprenda colocando a mão no código.

    Aprenda colocando em prática

    1. Aulas curtas: cada tópico tem explicação, exemplo, experimento, exercício e revisão.
    2. Editor de código: o Python roda de verdade no seu navegador. Altere o código e clique em “Executar código”.
    3. Exercícios: com dicas, uma de cada vez, se você travar.
    4. Verificar resposta: testa se o seu programa resolve o exercício.

    Tudo pronto para começar!

    O Inside Python tem cinco aulas, e você pode estudar na ordem que preferir. Seu progresso é salvo neste navegador, para você continuar de onde parou.
